How Change key for worship songs works here

This page is built around a specific rehearsal situation rather than a feature name, so the starting settings differ from the generic tool page. Every page on this site loads one shared workbench: you open a single audio file you have the rights to use, set speed, key, loop points and effects once, then render as many versions as you need from that same file.

Where this page starts

No preset is applied: speed 1.00x, 0 semitones, reverb off, center cancellation off and output gain at 0 dB. You can change any of those values before exporting; the preset is a starting point, not a limit.

The exact steps on this page

In practice, set the Transpose value once per song and keep it in the practice sheet so the same set list opens with the same keys next week. The result is rendered with OfflineAudioContext and encoded to WAV inside your browser. Nothing is uploaded and there is no account.

What comes out

A 16-bit WAV of the full track or only the A-B region, optionally peak-normalized to -1 dBFS. Batch export writes several versions plus a plain-text manifest, and the share link carries speed, key, loop points and notes - never the audio.

Frequently asked questions

Do I need an account, and are my files uploaded?

No. Audio is decoded and processed inside your browser using the Web Audio API. There is no account, no upload and no watermark.

Can I use copyrighted songs?

Only open audio you have the right to use: your own recordings, licensed material or student work. We do not provide songs, lyrics, or downloads from streaming or video platforms.

What exactly do I share with a student?

A practice sheet - speed, key shift, loop points, tempo and your note - encoded in the link. No audio travels with it, so the student opens their own legally held copy of the song and gets your exact settings.

Does slowing a song change the key?

No. The speed control keeps the original pitch. Transposition is applied when you export, so the practice sheet and the WAV agree.

Which browsers and formats work?

Current Chrome, Edge, Firefox and Safari. Any format your browser decodes (MP3, WAV, M4A/AAC, OGG, FLAC). Exports are 16-bit WAV.
